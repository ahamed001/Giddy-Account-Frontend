# Security Audit Logs - Frontend

A modern React dashboard for uploading, browsing, searching, filtering, sorting, and paginating security audit logs. All data operations are performed on the backend to ensure scalability and consistent performance.

## Overview

This dashboard allows security engineers to investigate audit logs generated by an application.

Users can:

- Upload audit logs using a JSON file.
- Search logs.
- Filter logs by multiple fields.
- Sort logs.
- Browse paginated results.

Every interaction communicates with the backend API. No filtering, sorting, searching, or pagination is performed in the browser.

---

## Features

- Upload audit logs using a JSON file.
- Debounced search across:
  - Actor
  - Resource
  - IP Address
- Dynamic filters for:
  - Role
  - Action
  - Resource Type
  - Severity
  - Status
  - Region
- Server-side sorting by:
  - Timestamp
  - Actor
  - Severity
- Server-side pagination.
- Responsive data table.
- Severity and status badges.
- Human-readable timestamps.
- Loading, empty, and error states.


```env

```



---

## How It Works

The frontend communicates with the backend for every operation.

Whenever the user:

- uploads logs
- searches
- changes filters
- changes sorting
- changes pages

the frontend makes an API request and renders only the returned records.

This keeps the application scalable even for datasets containing thousands of audit logs.
